# AtlasFind

**Find the right software. Faster.**

AtlasFind is a software discovery and comparison platform built with Flask.

## Current Version

v0.1.0

## Current Features

- Software search
- Tool cards
- Tool detail pages
- Comparison page
- Dark and light themes
- Responsive design
- JSON-based dataset

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
