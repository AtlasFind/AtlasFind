# AtlasFind v1.0.4 Product Marker Guard

Bu yama çok ürünlü şirketlerin genel favicon veya touch-icon dosyalarının ürün logosu olarak otomatik onaylanmasını engeller.

Örnekler:
- Microsoft genel faviconu OneDrive veya Teams logosu değildir.
- AWS genel touch iconu Amazon S3 veya Redshift logosu değildir.
- Apple genel touch iconu Safari, Logic Pro veya GarageBand logosu değildir.

Kurumsal alan adlarında ürün adına özgü bir belirteç dosya URL'sinde, hostta, dosya yolunda veya logo metadata alanlarında bulunmak zorundadır.
