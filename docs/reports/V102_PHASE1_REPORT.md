# AtlasFind v1.0.2 Phase 1 Report

## Scope

This phase establishes the modular data foundation. It does not claim that the 600 legacy records are factually verified.

## Source of truth

`data/catalog/manifest.json` and the category JSON files listed by it are now the canonical catalog source. `data/tools.json` is generated by `scripts/build_catalog.py` for backward compatibility with older scripts.

## Verification policy

All migrated legacy records are marked `pending`. A record may only move to `partially_verified` or `verified` after its `source_references` are populated with reviewed HTTPS sources and review dates.

## Commands

```powershell
py scripts\build_catalog.py
py scripts\validate_catalog_v102.py
py scripts\benchmark_catalog_v102.py
py scripts\migrate_json_to_sqlite.py
```

## Rollback

Restore the v1.0.1 tag or ZIP. No database migration is automatically forced by this phase. The existing SQLite database remains compatible until an explicit catalog migration is run.
